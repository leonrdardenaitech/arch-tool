# ATLAS CORE: Cybersecurity Frameworks Synthesized

## 1. CIS Critical Security Controls (The "To-Do List")
- **Focus:** Technical hygiene and immediate risk reduction.
- **Structure:** 18 prioritized controls.
- **Key Concept:** **Implementation Group 1 (IG1)** is the baseline for "essential cyber hygiene" in small/new organizations.
- **Best Use Case:** Practical checklists for securing infrastructure.

## 2. NIST Cybersecurity Framework (The "Common Language")
- **Focus:** Risk management and executive communication.
- **Structure:** 5 Core Functions:
  1. **IDENTIFY:** Inventory assets and assess risk.
  2. **PROTECT:** Implement safeguards (Access control, training).
  3. **DETECT:** Monitor for anomalies and events.
  4. **RESPOND:** Execute an incident response plan.
  5. **RECOVER:** Restore services and learn from the event.
- **Best Use Case:** Aligning security with business goals.

## 3. ISO/IEC 27001 (The "Formal Standard")
- **Focus:** Information Security Management System (ISMS).
- **Structure:** 93 Controls + rigorous process documentation.
- **Key Concept:** Certification-oriented for B2B trust.
- **Best Use Case:** Demonstrating compliance to external enterprise clients.

## Implementation Path
- **Step 1:** Use **CIS IG1** for technical hardening.
- **Step 2:** Use **NIST CSF** for organizational strategy.
- **Step 3:** Scale to **ISO 27001** when certification is required.
